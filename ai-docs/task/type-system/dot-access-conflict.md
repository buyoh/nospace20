# 型システム: ドットアクセスと名前空間の関係

## 解決済み

名前空間のアクセスに `$` が採用されたため、`.` と名前空間の衝突は**発生しない**。

```
s.field          # 構造体フィールドアクセス (.)
MySpace$x        # 名前空間の修飾名アクセス ($)
```

- `.` は構造体フィールドアクセス専用
- `$` は名前空間の修飾名アクセス専用
- 両者は構文レベルで完全に分離されており、意味解析での曖昧性解決は不要

## 補足: 名前空間内の構造体フィールドアクセス

名前空間内の構造体変数にアクセスし、そのフィールドを参照するケース:

```
namespace: A {
  let: s@Point;
}
A$s.x;           # 名前空間 A の変数 s のフィールド x #
```

- `A$s` は名前空間解決（`$` によるマングリング）
- `.x` は構造体フィールドアクセス
- パース順序: `(A$s).x` — `$` はトークナイザ段階で識別子に結合されるため、`.` とは独立に処理される
