# Whitespace インタプリタテスト失敗調査

## 概要

Whitespace インタプリタ直接テストの実装において、30テスト中17テストが成功したが、13テストが失敗した。
失敗の原因を調査し、テストケースの修正またはインタプリタの修正が必要かを判断する。

## 失敗したテストの分類

### カテゴリ1: 数値エンコーディングの問題

#### stack/push_negative_001
- **期待値**: -3
- **実際の値**: (要実行確認)
- **WSA内容**: `SSTTTN` (Push -3)
- **原因**: 数値エンコーディングが不正確な可能性
- **対策**: エンコーディングを再確認し、修正

### カテゴリ2: 算術演算の問題

#### arith/sub_001
- **期待値**: 7 (10 - 3)
- **実際の値**: (要実行確認)
- **原因**: 減算のオペランド順序またはスタック順序の問題の可能性
- **対策**: Whitespace仕様と実装を確認

#### arith/mul_001
- **期待値**: 42 (6 * 7)
- **実際の値**: (要実行確認)
- **原因**: 乗算命令の実装確認が必要
- **対策**: テストケースとインタプリタのデバッグ

#### arith/combined_001
- **期待値**: 20 ((2 + 3) * 4)
- **実際の値**: 6
- **原因**: スタック順序または演算順序の問題
- **対策**: ステップバイステップでスタック状態を追跡

### カテゴリ3: フロー制御の問題

#### flow/call_return_001
- **期待値**: 42
- **原因**: サブルーチン呼び出しまたは復帰の実装確認が必要
- **対策**: プログラムカウンタとコールスタックの動作を確認

#### flow/jump_if_neg_true_001
- **期待値**: 1
- **実際の値**: 991
- **原因**: 条件ジャンプの実装またはラベルの問題
- **対策**: ジャンプ先とスキップされるべき命令を確認

#### flow/jump_if_neg_false_001, flow/jump_if_zero_false_001
- **期待値**: 2
- **原因**: 条件ジャンプが正しく動作していない可能性
- **対策**: 条件判定とジャンプ実装を確認

#### flow/loop_simple_001
- **期待値**: 321 (カウントダウンループ)
- **原因**: ループの実装またはWSAエンコーディングの問題
- **対策**: ループロジックを詳細に追跡

### カテゴリ4: エラーテスト（全失敗）

すべてのエラーテストが失敗している。これらはランタイムエラーを期待しているが、エラーが検出されていない、または異なるエラーが発生している可能性がある。

#### errors/stack_underflow_001
- **期待エラー**: StackUnderflow
- **対策**: 空スタックでの算術演算時のエラー検出を確認

#### errors/div_zero_001
- **期待エラー**: DivisionByZero
- **対策**: ゼロ除算時のエラー検出を確認

#### errors/callstack_underflow_001
- **期待エラー**: CallStackUnderflow
- **対策**: Return命令でのコールスタック確認処理を検証

#### errors/undefined_label_001
- **期待エラー**: UndefinedLabel
- **対策**: ジャンプ先ラベルの存在確認処理を検証

## 調査手順

### ステップ1: 個別テストの詳細実行

失敗した各テストを個別に実行し、詳細なエラーメッセージと実際の出力を記録する。

```bash
cargo test --test whitespace_direct_test test_ws_stack_push_negative_001 -- --nocapture
```

### ステップ2: WSAデコード結果の確認

失敗したテストのWSAファイルをデコードし、正しい Whitespace コードになっているか確認する。

### ステップ3: インタプリタのデバッグ

必要に応じて、WhitespaceVM のステップ実行やスタック状態のトレースを行う。

### ステップ4: 修正と再テスト

テストケースまたはインタプリタを修正し、再度テストを実行する。
