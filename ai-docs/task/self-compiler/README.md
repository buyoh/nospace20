# セルフコンパイラ用縮小仕様（nospace-core）

## 概要

nospace 言語でセルフコンパイラを実装するために、言語の機能を最小限に縮小した仕様「nospace-core」を策定する。

**目標**: nospace で書かれたコンパイラが、nospace-core プログラムをコンパイルできること。

## 設計方針

1. **互換性**: nospace-core プログラムは、完全な nospace 仕様でも正しく動作する（nospace-core は nospace の厳密なサブセット）
2. **十分性**: セルフコンパイラの実装に必要な全ての機能を含む
3. **簡素性**: セルフコンパイラが解析・コンパイルすべき言語機能を最小化し、実装難易度を下げる

## nospace-core と nospace の関係

```
nospace-core ⊂ nospace

nospace-core プログラム → nospace インタプリタ/コンパイラで実行可能 ✓
nospace プログラム       → nospace-core コンパイラで実行不可の場合あり
```

### 主な制限事項（概要）

| 機能 | nospace | nospace-core | 理由 |
|------|---------|-------------|------|
| ブロックスコープ変数 | ✓ | ✗ | スコープ解析の簡略化 |
| static 変数 | ✓ | ✗ | メモリ管理の簡略化 |
| ネストした関数定義 | ✓ | ✗ | スコープ解析の簡略化 |
| 文字列リテラル | (未実装) | ✗ | 未実装のため対象外 |
| final/const | (未実装) | ✗ | 未実装のため対象外 |
| 型システム | (未実装) | ✗ | 未実装のため対象外 |
| `__trace` | ✓ | ✗ | テスト専用のため不要 |
| `__assert_not` | ✓ | ✗ | 簡略化（`__assert` で代替可能） |
| `__getiv` / `__getcv` | ✓ (非推奨) | ✗ | 非推奨のため除外 |

## セルフコンパイラの構成イメージ

```
nospace-core ソースコード
       │
       ▼
  ┌──────────┐
  │ 字句解析  │  __getc() でソースを読み取り、トークン列を配列に格納
  └──────────┘
       │
       ▼
  ┌──────────┐
  │ 構文解析  │  トークン列から AST をアリーナ(配列)ベースで構築
  └──────────┘
       │
       ▼
  ┌──────────┐
  │ コード生成 │  AST を走査し、__putc() でターゲットコードを出力
  └──────────┘
```

### セルフコンパイラが使用する主要なデータ構造

- **ソースバッファ**: 固定長配列（`let: src[MAX_SRC];`）
- **トークン列**: 固定長配列（トークン種別 + 値 + 位置情報）
- **AST ノード**: アリーナアロケーション（配列ベースのツリー構造）
- **シンボルテーブル**: 線形探索ベースのテーブル（配列）

全てのデータ構造は固定長配列と参照（ポインタ演算）で実現する。

## 実装の前提条件

- 配列、参照/間接参照が正しく動作すること（実装済み）
- I/O 組み込み関数（`__getc`, `__putc`, `__puti`）が動作すること（実装済み）
- 変数の初期化が動作すること（実装済み）
