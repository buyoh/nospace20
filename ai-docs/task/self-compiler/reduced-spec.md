# nospace-core 仕様書

nospace 言語のサブセット。セルフコンパイラ実装のために機能を縮小した仕様。
nospace-core で書かれたプログラムは、完全な nospace 仕様と互換性がある。

---

## 1 リテラル・識別子

### 1.1 数値リテラル

10進整数と16進整数に対応。負の数は単項マイナス演算子で表現する。

```
0
42
-7
0xFF    # 255 (16進数) #
0x10    # 16 (16進数) #
```

> nospace 仕様と同一。変更なし。

### 1.2 識別子

識別子は英字またはアンダースコアで始まり、英数字またはアンダースコアが続く。

```
x
_foo
myVar123
```

正規表現: `[A-Za-z_][A-Za-z0-9_]*`

> nospace 仕様と同一。変更なし。

### 1.3 文字リテラル

単一の文字をシングルクォートで囲むと、そのASCII値（整数）として扱われる。

```
'A'      # 65 #
'0'      # 48 #
'\n'     # 10 (改行) #
'\t'     # 9 (タブ) #
'\s'     # 32 (スペース) #
'\\'     # 92 (バックスラッシュ) #
'\''     # 39 (シングルクォート) #
'\x41'   # 65 ('A') 16進数エスケープシーケンス #
```

エスケープシーケンス:

| シーケンス | 値 | 説明 |
|------------|-----|------|
| `\n` | 10 | 改行 (LF) |
| `\r` | 13 | 復帰 (CR) |
| `\t` | 9 | タブ |
| `\s` | 32 | スペース |
| `\\` | 92 | バックスラッシュ |
| `\'` | 39 | シングルクォート |
| `\xHH` | 0-255 | 16進数エスケープシーケンス (HHは2桁の16進数) |

空の文字リテラルは不正。
半角スペース等の空白文字は文字リテラルの中であっても無視されるため、エスケープを使用すること。

> nospace 仕様と同一。変更なし。

### 1.4 コメント

`#` で囲まれた部分がコメントとして扱われる。

```
# これはコメント #
x = 1; # 行末コメント # y = 2;
```

> nospace 仕様と同一。変更なし。

## 2 演算

### 2.1 四則演算・剰余演算

```
2 + 3;
2 - 3 * 5;
(2 - 3) * 5;
3 * 4 / (1 + 2);
7 % 3;     # 1 #
```

> nospace 仕様と同一。変更なし。

### 2.2 単項演算子

```
-x         # 符号反転 #
!x         # 論理NOT: 0なら 1、非0なら 0 #
```

> nospace 仕様と同一。変更なし。

### 2.3 比較演算子

```
1 == 1     # 等しい: 真なら 1、偽なら 0 #
1 != 2     # 等しくない #
1 < 2      # 小なり #
1 <= 2     # 以下 #
2 > 1      # 大なり #
2 >= 1     # 以上 #
```

> nospace 仕様と同一。変更なし。

### 2.4 論理演算子

```
1 && 1     # 論理AND: 短絡評価 #
1 || 0     # 論理OR: 短絡評価 #
```

- `&&` : 短絡評価。左辺が 0 なら右辺を評価せず 0 を返す
- `||` : 短絡評価。左辺が非0なら右辺を評価せずその値を返す

> nospace 仕様と同一。変更なし。

### 2.5 複合代入演算子

```
x += 1;    # x = x + 1 と等価 #
x -= 2;    # x = x - 2 と等価 #
x *= 3;    # x = x * 3 と等価 #
x /= 4;    # x = x / 4 と等価 #
x %= 5;    # x = x % 5 と等価 #
```

> nospace 仕様と同一。変更なし。

### 2.6 参照・間接参照演算子

```
&x         # 変数 x の参照（アドレス）を取得 #
*p         # 参照 p をデリファレンス（間接参照） #
```

- `&` : 変数または配列要素の参照を取得する。
- `*` : 参照をデリファレンスして、参照先の値を取得または代入する。
- 参照先が開放済みの場合の動作は未定義。

> nospace 仕様と同一。変更なし。

### 2.7 演算子の優先順位

高い順:

1. 単項演算子 (`-`, `!`, `&`, `*`)
2. 乗除算・剰余 (`*`, `/`, `%`)
3. 加減算 (`+`, `-`)
4. 比較演算子 (`==`, `!=`, `<`, `<=`, `>`, `>=`)
5. 論理AND (`&&`)
6. 論理OR (`||`)
7. 代入・複合代入 (`=`, `+=`, `-=`, `*=`, `/=`, `%=`)

> nospace 仕様と同一。変更なし。

## 3 組み込み識別子

### 3.1 標準入出力

```
__puti(42);            # 整数を10進数で出力 #
__putc(65);            # 文字（ASCII）を出力 #
let: n; n = __geti();  # 整数を入力 #
let: c; c = __getc();  # 1文字を入力 #
```

| 識別子 | 説明 |
|--------|------|
| `__puti(x)` | 整数 x を10進数で標準出力に出力し、x を返す |
| `__putc(x)` | x をASCII文字として標準出力に出力し、x を返す |
| `__geti()` | 標準入力から整数を読み込み、その値を返す |
| `__getc()` | 標準入力から1文字を読み込み、ASCII値を返す |

> nospace 仕様から以下を除外:
> - `__clog(x)` — デバッグ専用（開発時に使用してよいが nospace-core 仕様外）
> - `__assert(x)` — デバッグ専用（開発時に使用してよいが nospace-core 仕様外）
> - `__assert_not(x)` — デバッグ専用
> - `__trace(key)` — テスト専用
> - `__getiv(p)` / `__getcv(p)` — 非推奨

**注意**: `__clog` および `__assert` はセルフコンパイラの開発・デバッグ時に任意に使用してよい。
ただし、nospace-core コンパイラがこれらを解釈する必要はない。

## 4 変数定義

### 4.1 基本的な変数宣言

```
let: x;                # 変数 x を宣言（初期値 0） #
let: x(5);             # 変数 x を 5 で初期化 #
let: a, b;             # 複数変数を宣言 #
let: a(1), b(2);       # 複数変数を初期化して宣言 #
```

- `let: x;` で変数 x を定義する。初期値は 0。
- `let: x(expr);` で初期値を指定できる。
- カンマ区切りで複数変数を同時に宣言できる。
- 変数は関数スコープに属し、ホイスティングされる（定義位置に関わらず、関数の先頭で定義されたのと同等）。

> nospace 仕様と同一。

### 4.2 配列

```
let: arr[4];                      # サイズ4の配列（初期値 0） #
arr[0] = 1;                       # 要素への代入 #
let: arr2[3](10, 20, 30);         # 初期値付き配列宣言 #
```

- 配列サイズは定数のみ指定可能。
- `arr[i]` で i 番目の要素を参照する（0 始まり）。
- `arr` 単体は `arr[0]` と同義。
- `&arr` は配列の先頭要素の参照を取得する。

> nospace 仕様と同一。変更なし。

### 4.3 グローバル変数

```
let: global_var;       # グローバル変数 #

func: main() {
    global_var = 42;
    __puti(global_var);
}
```

- 関数外の `let:` 宣言はグローバル変数を作成する。
- グローバル変数は全ての関数からアクセス可能。

> nospace 仕様と同一。変更なし。

### 4.4 スコープ規則

nospace-core では以下のスコープ規則を適用する:

- **グローバルスコープ**: 関数外で宣言された変数。全関数からアクセス可能。
- **関数スコープ**: 関数内で宣言された変数。関数内のどこからでもアクセス可能（ホイスティング）。
- 関数スコープの変数は、制御構文（if/while）のブロック内からもアクセス可能。

```
func: main() {
    let: x;
    x = 1;
    if: 1 {
        x = 2;         # ok: 関数スコープの変数にアクセス #
        # ブロック内で let: を使用しない #
    };
}
```

> **nospace 仕様との差異（縮小箇所）**:
> - ブロックスコープ（if/while 内での `let:` 宣言による独立スコープ）は nospace-core では使用しない。
>   `let:` は関数の直下またはグローバルスコープでのみ使用する。
> - `static:` 変数は nospace-core には含まない。
> - これらの制限はプログラムが nospace でも正しく動作することに影響しない。
>   全ての `let:` を関数トップに書くことは nospace でも有効である。

## 5 関数定義

```
func: add(a, b) {
    return: a + b;
}

func: main() {
    let: result;
    result = add(3, 4);
    __puti(result);
    return: 0;
}
```

- `func: 関数名(引数, ...) { 文... }` の形式で関数を定義する。
- 関数はホイスティングされる（定義より前に呼び出し可能）。
- `main` 関数がエントリポイントとなる。
- `return:` がない場合、0 を返す。
- 再帰呼び出しが可能。
- **関数定義はトップレベル（グローバルスコープ）でのみ記述する。**

> **nospace 仕様との差異（縮小箇所）**:
> - ネストした関数定義（関数内での関数定義）は nospace-core では使用しない。
> - これは制限であり、動作の変更ではない。トップレベルで全関数を定義することは nospace でも有効。

## 6 制御構文

### 6.1 while 文

```
while: 条件式 {
    文...
};
```

- 条件式が 0 以外の間、ブロックを繰り返し実行する。
- while は式として扱われ、末尾に `;` が必要。
- 式としての値は常に 0 を返す。

> nospace 仕様と同一。変更なし。

### 6.2 if 文

```
if: 条件式 {
    文...
};

if: 条件式 {
    文...
} else: {
    文...
};

if: 条件式 {
    文...
} else: if: 条件式 {
    文...
} else: {
    文...
};
```

- 条件式が 0 以外ならブロックを実行。
- `else:` ブロックは省略可能。
- `else: if:` で連鎖可能。
- if は式として扱われ、末尾に `;` が必要。
- 式としての値は常に 0 を返す。

> nospace 仕様と同一。変更なし。

### 6.3 break / continue

```
break;       # 最も内側のループを抜ける #
continue;    # 最も内側のループの次の反復へ進む #
```

> nospace 仕様と同一。変更なし。

### 6.4 return

```
return: 式;  # 式の値を返して関数を終了する #
return;      # 0 を返して関数を終了する #
```

> nospace 仕様と同一。変更なし。

## 7 文法まとめ

### 7.1 プログラム構造

```
プログラム     ::= (グローバル宣言)*
グローバル宣言 ::= 変数宣言 | 関数定義
変数宣言       ::= "let:" 変数リスト ";"
関数定義       ::= "func:" 識別子 "(" 引数リスト ")" "{" 文* "}"
```

### 7.2 文

```
文 ::= 変数宣言
     | "return:" 式 ";"
     | "return" ";"
     | "break" ";"
     | "continue" ";"
     | 式 ";"
```

### 7.3 式

```
式     ::= 代入式
代入式 ::= 論理OR式 (("=" | "+=" | "-=" | "*=" | "/=" | "%=") 代入式)?
論理OR式  ::= 論理AND式 ("||" 論理AND式)*
論理AND式 ::= 比較式 ("&&" 比較式)*
比較式    ::= 加減式 (("==" | "!=" | "<" | "<=" | ">" | ">=") 加減式)?
加減式    ::= 乗除式 (("+" | "-") 乗除式)*
乗除式    ::= 単項式 (("*" | "/" | "%") 単項式)*
単項式    ::= ("-" | "!" | "&" | "*") 単項式 | 後置式
後置式    ::= 一次式 ("[" 式 "]")*
一次式    ::= 数値リテラル
            | 文字リテラル
            | 識別子 ("(" 式リスト ")")?
            | "(" 式 ")"
            | "if:" 式 "{" 文* "}" ("else:" "{" 文* "}")?
            | "while:" 式 "{" 文* "}"
```
