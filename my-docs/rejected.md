## I 無名スコープの修正

`{...}` と `(...)` が類似しているため、`{...}` を削除し、`(...)` に統合出来ないか検討する。
`{}` を別の用途に使えるようにするため。タプルとか。`:{}`で回避できなくもない

- `2 * (3 + 4)` のように使いたい。
- 一番簡単な方法としては、文と解釈すること。デメリットは、`2*(3+4;)` のように `;` が必要になること。
  - 最後の文は `;` を省略できるようにする（？）
- 式も文も両方許容する（ように実装できるか？）
  - `2 * (let: x(3); x + 4;)` のように、式の中で文も使えるようにする。
- 関数定義も while も `(...)` に？
  - `func: add(a, b) { return: a + b; }` → `func: add(a, b) ( return: a + b; )`
