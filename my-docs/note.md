## 仕様の疑問点

ホイスティング＋初期化

```
x = 5;
let: x(9);
__clog(x);  # 5 を出力するのか？9 を出力するのか？ #
```

static

- 変数の初期化タイミングは global 変数と同様、main が呼び出される前。変数なと定数以外で初期化できない
- static 変数は、static でない global変数より先に初期化される

名前付きスコープ

- `::` : `:` を識別子に使うので。
- `.`
- `->` : 関数
- `@` : 型に使いたい
- `$`

```
let: x(1);
scope: Scope1 {
  let: x(2);
  scope: Scope2 {
    let: x(3);
  }
  __clog(x);  # 2 を出力 #
  __clog(Scope2::x);  # 3 を出力 #
}
```

if 式。簡単だが、elseが無い場合の扱いは？
型を導入しなければ 0 を返せば ok。

```
let: x;
x = if: 1 {
  10;
} else: {
  20;
};
__clog(x);  # 10 を出力 #
```
