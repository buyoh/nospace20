# spec

## 前提

- UTF-8 でエンコードされたテキストファイルを対象とする。

## リテラル・識別子

### 数値リテラル

10進整数と16進整数に対応。負の数は単項マイナス演算子で表現する。

```
0
42
-7
0xFF    # 255 (16進数) #
0x10    # 16 (16進数) #
```

### 識別子

識別子は英字またはアンダースコアで始まり、英数字またはアンダースコアが続く。

```
x
_foo
myVar123
```

正規表現: `[A-Za-z_][A-Za-z0-9_]*`

### 予約語

- `__` で始まる識別子は組み込み識別子として予約されている。エラーにはならないが、ユーザーコードで使用しないことが推奨される。
- グローバルスコープの `__main` はエントリポイント関数として予約されている。

### 文字リテラル

単一の文字をシングルクォートで囲むと、そのASCII値（整数）として扱われる。

```
'A'      # 65 #
'0'      # 48 #
'\n'     # 10 (改行) #
'\t'     # 9 (タブ) #
'\s'     # 32 (スペース) #
'\\'    # 92 (バックスラッシュ) #
'\''    # 39 (シングルクォート) #
'\x41'   # 65 ('A') 16進数エスケープシーケンス #
'\xFF'   # 255 (16進数エスケープシーケンス) #
'\xFF03'   # (16進数エスケープシーケンス) #
'\x1F363'   # (16進数エスケープシーケンス) (4byte まで対応) #
```

エスケープシーケンス:

| シーケンス | 値 | 説明 |
|------------|-----|------|
| `\n` | 10 | 改行 (LF) |
| `\r` | 13 | 復帰 (CR) |
| `\t` | 9 | タブ |
| `\s` | 32 | スペース |
| `\\` | 92 | バックスラッシュ |
| `\'` | 39 | シングルクォート |
| `\xHH..` | 可変 | 16進数エスケープシーケンス (2桁以上の16進数、貪欲に読み取り) |

空の文字リテラルは不正。
半角スペース等の空白文字は文字リテラルの中であっても無視されるため、エスケープを使用すること。

### コメント

`#` で囲まれた部分がコメントとして扱われる。

```
# これはコメント #
x = 1; # 行末コメント # y = 2;
```

## 演算

### 四則演算

```
2+3;
2 + 3;
2 - 3*5;
(2-3)*5;
3*4/(1+2);
```

リテラル: 直接コード上に記述する値のこと。`2`
式: `2+3`
文: `2+3;`

### 単項演算子

```
-x
--x  # 二重否定 #
```

- `-` : 符号反転

### 比較演算子

```
1 == 1   # 等しい: 真なら 1、偽なら 0 #
1 != 2   # 等しくない #
1 < 2    # 小なり #
1 <= 2   # 以下 #
2 > 1    # 大なり #
2 >= 1   # 以上 #
```

### 論理演算子

```
1 && 1   # 論理AND: 両方が非0なら 1、そうでなければ 0 #
1 || 0   # 論理OR: どちらかが非0なら 1、両方が0なら 0 #
!0       # 論理NOT: 0なら 1、非0なら 0 #
```

- `&&` : 短絡評価。左辺が 0 なら右辺を評価せず 0 を返す
- `||` : 短絡評価。左辺が非0なら右辺を評価せずその値を返す
- `!` : 単項演算子。0 なら 1、非0 なら 0

### 複合代入演算子

```
x += 1;   # x = x + 1 と等価 #
x -= 2;   # x = x - 2 と等価 #
x *= 3;   # x = x * 3 と等価 #
x /= 4;   # x = x / 4 と等価 #
x %= 5;   # x = x % 5 と等価 #
x += y += 3;  # y += 3; x += y; と等価 #
```

### 剰余演算子

```
7 % 3    # 1 (7 を 3 で割った余り) #
```

### 参照・間接参照演算子

```
&x       # 変数 x の参照（アドレス）を取得 #
*p       # 参照 p をデリファレンス（間接参照） #
```

- `&` : 変数の参照を取得する。変数に対してのみ使用可能。
- `*` : 参照をデリファレンスして、参照先の値を取得または代入する。
- 参照はC言語のポインタに似ているが、本言語では「参照」と呼ぶ。
- スタック上の変数、static変数、グローバル変数など制限なく参照を取得できる。
- 参照先が開放済みの場合の動作は未定義。特にプロテクションは行わない。

### 演算子の優先順位

高い順:

1. 単項演算子 (`-`, `!`)
2. 乗除算 (`*`, `/`)
3. 加減算 (`+`, `-`)
4. 比較演算子 (`==`, `!=`, `<`, `<=`, `>`, `>=`)
5. 論理AND (`&&`)
6. 論理OR (`||`)
7. 代入 (`=`)

## 代入・変数定義

```
let:x; let:y; x=3; y=2; x=x+y; y=x+y;
```

- `let:x` は、識別子 x を定義して、スタックに領域を作成する。作成された領域は、スコープを抜けるまで有効である。
- どこで定義しても、スコープの先頭で定義されたものと同等になる。これは、javascript の巻き上げ (hoisting) と同等の動作である。
- 変数の初期値は未定義である。初期値を指定しない場合、読み出し時の値は不定となる他、ランタイムによっては実行時エラーとなる。
- `final` 再代入不可変数。詳細は後述。
- `constexpr` コンパイル時定数。詳細は後述。
- 初期値の指定。
- グローバル変数。
- ブロックスコープ内での変数定義。

```
func: foobar(a, b) {
  final: x(a + b);       # 再代入不可 #
  constexpr: y(57);      # コンパイル時定数 #
  # constexpr: z(a + b); コンパイルエラー: ランタイム値を参照 #
  # x = 57; コンパイルエラー: final 変数への再代入 #
  &x;                    # OK: final 変数のアドレスは取得可能 #
}
```

### ホイスティング

非推奨だが、宣言より前に変数や関数を使用することができる。ただし、初期値は宣言のある行まで未定義である。

```
# __clog(a); コンパイルエラーではないが、a は未定義の値を持つ #
a=5;
__clog(a); # 5 #
let: a(4);
__clog(a); # 4 #
```

### 変数の初期化

変数宣言時に初期値を指定できる。

```
let: z;              # z の初期値は未定義 #
let: u, v;           # 複数変数を初期化して宣言 #
let: x(5);           # x を 5 で初期化 #
let: a(1), b(2);     # 複数変数を初期化して宣言 #
```

```
__clog(a);  # 初期値は未定義 #
a=5;  # ホイスティングにより有効 #
__clog(a); # 5 #
let: a(3);
__clog(a); # 3 #
```

### 配列

配列は固定長で、宣言時にサイズを指定する。

```
let: arr[4];                   # 配列長4の配列を宣言 #
arr[0] = 1;                    # 要素へのアクセス #
let: arr2[3]([10, 20, 30]);    # 初期値付き配列宣言 #
let: arr3[]([10, 20, 30]);     # 配列長省略（3と推論）#
```

- 配列長は定数のみ指定可能。
- 初期値が与えられているとき、`[]`内のサイズは省略可能。初期値の数から配列長を推論する。
- 配列長より初期値の数が多い場合はエラー。
- 配列長より初期値の数が少ない場合は、残りの要素は未初期化状態である。
- `arr` 単体は `arr[0]` と同義。C言語とは異なり、配列名だけでも最初の要素を指す。
- `&arr` は配列の先頭要素の参照を取得する。
- `arr[i]` は、`*(&arr + i)` と同義
  - `arr[i]` で i 番目の要素を参照する（0から始まる）。

多次元配列は未実装。（型実装後検討）

### 文字列

初期値付き配列宣言の糖衣構文。末尾は自動的にヌル文字で終端される。
文字列の中であっても空白文字は無視されるため、エスケープを使用すること。

```
let: str1[]("Hello");      # サイズ6の配列を宣言（サイズ省略）#
let: str2[6]("Hello");     # サイズ明示 #
let: str3[6]('H', 'e', 'l', 'l', 'o', '\0');  # 同等 #
```

### constexpr

コンパイル時に評価される定数式。変数ではなくコンパイル時の名前置換として機能する。

```
constexpr: PI(3);                  # リテラル定数 #
constexpr: SIZE(2 + 3);            # コンパイル時式（5 に解決）#
constexpr: DOUBLE_PI(PI * 2);      # 他の constexpr を参照可能 #
# constexpr: X(variable);          コンパイルエラー: ランタイム変数は不可 #
# constexpr: Y(func1());           コンパイルエラー: 関数呼び出しは不可 #
```

- `constexpr: name(expr);` で `name` をコンパイル時定数として定義する。
- `expr` は定数式（リテラル・他の constexpr の四則演算・比較演算・論理演算のみ）でなければならない。
- スタックスロットを持たない（変数ではない）。`&name` は不可。
- 代入 `name = ...` は不可（定数であり変数ではない）。
- ホイスティングされる（定義より前に使用可能）。巡回参照はコンパイルエラー。
- カンマ区切りで複数の定数を同時に定義できる: `constexpr: A(1), B(2);`

### constexpr ブロック形式

複数の文を実行してその結果をコンパイル時定数とする形式。

```
constexpr: VALUE {
  let: tmp(3);
  tmp * tmp;   # = 9 #
};

constexpr: MAX {
  if: a - b { a; } else: { b; };
};
```

- `constexpr: name { 文... };` でブロック内の最後の式の値を定数として定義する。
- ブロック内では以下が使用可能:
  - `let: name(expr);` によるローカル変数の宣言・初期化
  - 算術・比較・論理演算
  - 代入 `=`・複合代入 `+=`, `-=`, `*=`, `/=`, `%=`（ローカル変数のみ）
  - `if: cond { ... } else: { ... }` による条件分岐
  - ネストしたブロック式 `{ ... }`
  - 解決済みの他の constexpr 定数の参照
- ブロック内では以下は禁止:
  - `while:`, `for:`, `repeat:` などのループ（コンパイル時評価不可）
  - 関数呼び出し（コンパイル時評価不可）
  - 配列宣言（`let: arr[N](0);`）
  - `static:`, `final:`, `constexpr:`, `alias:` の使用
- ブロック形式は単一定義のみ（カンマ区切り複数定義は不可）。
- 他の constexpr を参照する場合、参照先が辞書順で前に定義されている必要がある（解決済みであること）。

### final 変数

宣言時に初期値を設定し、以降の再代入を禁止する変数。

```
func: compute() { return: 42; }

func: __main() {
  final: x(10);          # 初期値付きで宣言 #
  final: y(compute());   # ランタイム値でも可 #
  # x = 20;             コンパイルエラー: final 変数への再代入 #
  # x += 1;             コンパイルエラー: 複合代入も不可 #
  &x;                    # OK: アドレス取得は可能 #
  __assert(x == 10);
}
```

- `final: name(expr);` で再代入不可の変数を定義する（スタックスロットを確保）。
- 変数としての実体を持つため、ランタイム値（関数の戻り値等）で初期化できる。
- 初期化後の代入・複合代入はすべてコンパイルエラーとなる。
- `&final_var` でアドレスを取得することは可能。
- `constexpr` との違い: `constexpr` は変数の実体を持たないコンパイル時定数。`final` は実体を持つランタイム変数。

## 関数定義

```
func: pow(a) {
  __clog(a);
  return: a*a;
}

func: __main() {
  let: x1; let: y1;
  let: x2; let: y2;
  x1 = 3; y1 = 4;
  x2 = 7; y2 = 3;
  __clog(pow(x2 - x1) + pow(y2 - y1));
  return: 0;
}
```

- `func: 関数名(引数, ...) { 文... }` の形式で関数を定義する。
- 関数はホイスティングされる（定義より前に呼び出し可能）。
- `__main` 関数がエントリポイントとなる。
- `return: 式;` で関数から値を返す。式がない場合は `return:;` と書く。
- 関数の戻り値型は自動推論される（→「型システム」節を参照）。
  - 本体に `return: 式;` がある関数は int 型を返す。
  - `return:` 文がない関数は void 型を返す。
  - 戻り値型が混在する関数はコンパイルエラーとなる。

## alias 定義

コンパイル時の名前置換機構。識別子エイリアスとブロックエイリアスの2種類がある。

### 識別子エイリアス

既存の識別子（関数名・変数名）に別名を付ける。

```
func: func1() { return: 42; }
alias: afunc(func1);

func: __main() {
  __puti(afunc());   # func1() と同じ。42 を出力 #
}
```

```
func: __main() {
  let: x(10);
  alias: y(x);
  y = 20;            # x = 20 と同じ #
  __assert(x == 20);
}
```

- `alias: name(target);` で `name` を `target` の別名として登録する。
- `name` が使用された箇所で `target` に名前解決される。
- target が関数なら関数として、変数なら変数として扱われる。
- エイリアスのエイリアスも可能（チェーン解決）。巡回参照はコンパイルエラー。
- ホイスティングされる（定義より前に使用可能）。

### ブロックエイリアス

文の列（ブロック）を名前に紐付け、呼び出し時にインライン展開する。

```
func: __main() {
  let: x(5);
  alias: inc_x { x = x + 1; };
  inc_x();           # ブロックが展開される #
  __assert(x == 6);  # 呼び出し元の x が変更される #
}
```

- `alias: name { 文... };` でブロックを `name` に紐付ける。
- `name()` の呼び出しで、ブロックの AST がインライン展開される。
- ブロック内の名前解決は**呼び出し元のスコープ**で行われる（マクロ的置換）。
- 引数は取れない。引数が必要な場合は `func:` を使用する。
- 戻り値はブロックの最後の式の値（ブロック式と同じ）。
- ホイスティングされる。巡回参照（再帰展開）はコンパイルエラー。

## 制御構文: 文

### return 文

```
func: add(a, b) {
  return: a + b;
}
```

- `return: 式;` : 式の値を返して関数を終了する
- `return:;` : 値を返さずに関数を終了する（void return）

### while 文

```
func: __main() {
  let:i;
  i=5;
  while:i{
    __clog(i);
    i=i-1;
  };
}
```

- `while: 条件式 { 文... };` の形式。
- 条件式が 0 以外の間、ブロックを繰り返し実行する。
- while は文である。式として使用することはできない。

### break 文 / continue 文

```
func: __main() {
  let: i;
  i = 10;
  while: i {
    i = i - 1;
    if: i - 5 {
      continue:;  # 次のループへ #
    };
    break:;  # ループを抜ける #
  };
}
```

- `break:;` : 最も内側のループを抜ける。
- `continue:;` : 最も内側のループの次の反復へ進む。

### repeat 文

`repeat` 文には3つの形式がある。`varname(init_number)` はカウンタ変数とその初期値で、`N` は**上限値**（`varname < N` の間ループ）。カウンタ変数は body 内で書き換え可能で、その場合ループ回数も変化する。

```
# Form 1: i が N を下回る間ループ。i は毎回 +1 される。
repeat: varname(init_number), N, body;

# Form 2: カウンタ付き無限ループ（break で脱出）
repeat: varname(init_number), body;

# Form 3: 無限ループ（break で脱出）
repeat: body;
```

```
# Form 1: i(0) から始めて i < 5 の間実行（i = 0, 1, 2, 3, 4）
repeat: i(0), 5, __puti(i);

# Form 1: i(1) から始めて i < 5 の間実行（i = 1, 2, 3, 4）
repeat: i(1), 5, __puti(i);

# Form 2: i(0) から始めて無限ループ
repeat: i(0), {
  if: i == 4 { break:; };
};

# Form 3: 無限ループ
repeat: {
  __putc('.');
};
```

### for 文

より柔軟なループ構文。4つのブロック（init, cond, step, body）で構成される。

```
for: { init_block } { cond_block } { step_block } { body_block };
```

- cond_block、step_block、body_block はinit_block スコープの子スコープであり、init_block で定義された変数にアクセス可能。
- cond_block が 0 以外の間、step_block と body_block を繰り返し実行する。
- step_block は body_block の後や continue が呼ばれたときに実行される。
- 省略は出来ないが、空のブロックを指定することは可能。

```
for: {
  let: i(10);
} {
  i > 0;
} {
  i -= 1;
} {
  __clog(i);
};
```

## 制御構文: 式

### if 式

```
func: __main() {
  let: x;
  x = 10;
  if: x - 5 {
    __clog(1);  # x != 5 の場合 #
  } else: {
    __clog(0);  # x == 5 の場合 #
  };
}
```

- `if: 条件式 { 文... };` または `if: 条件式 { 文... } else: { 文... };` の形式。
- 条件式が 0 以外の場合、最初のブロックを実行する。
- 条件式が 0 の場合、else ブロックを実行する（ある場合）。
- if は式であるため、末尾に `;` が必要。
- else なしの if は void 型である。
- else 付きの場合、then ブロックと else ブロックの最後の式の型が両方 int なら全体は int、いずれかが void なら全体は void となる。
- else if は `else: if: 条件式 { ... }` の形式で記述可能。

### ブロックスコープ 式

```
func: __main() {
  let: x;
  x = {
    let: a;
    a = 3;
    a;  # ブロックの値 #
  };
  __clog(x);  # 3 #
}
```

- `{ 文... }` : 独立したブロックスコープを作成する式。
- ブロック内で `let:` で宣言した変数は、ブロック終了時に破棄される。
- ブロックの型は、最後に評価された式の型となる。最後の式が int なら int、void なら void。
- ブロックが空の場合は void 型となる。
- `break`、`continue`、`return` は通常通り機能する。
- 親スコープの変数にアクセス可能。

```
func: __main() {
  let: result;
  result = {
    let: a(10);
    {
      let: b(5);
      a + b;  # ネストしたブロックの値 #
    };        # 15を返す #
  };          # 15を返す #
  __assert(result == 15);
  
  {};  # 空ブロックは void #
}
```

```
# ブロック式の中で複数の文を実行して最後に値を返す #
__puti({let: x, y; x = 3; y = 4; x + y;});
```

## スコープ

```
func: __main() {
  let:a;
  a = 1;
  if:1{
    let:b;
    a = 2;  # ok #
    b = 3;  # ok #
    # end of life of b #
  };
  # b = 4; # # Bad #
}
```

- スコープとは、変数が有効な範囲のこと。
- スコープは親子関係を持つ。
- 子スコープから親スコープの変数にアクセス可能。親スコープから子スコープの変数にはアクセス不可。
- ブロックスコープ、関数スコープ、グローバルスコープがある。
  - ブロックスコープは、`if`、`while`、`{}` などのブロックごとに作られる。
  - 関数スコープは、関数ごとに作られる。親スコープとはライフタイムが異なるため、static でない親の変数にアクセスすることはできない。
  - グローバルスコープは、全てのスコープの親となる。グローバル変数はここで定義される。

```
let: global_var;  # グローバル変数 #

func: setter() {
  static: static_var;  # static変数 #
  static_var += 1;
  __clog(static_var);  # 呼び出される度に 1, 2, 3, ... と増加 #
  global_var = static_var;  # グローバル変数に代入 #
}

func: __main() {
  setter();
  __assert(global_var == 1);
  setter();
  __assert(global_var == 2);
}
```

- static 変数は、グローバルスコープの変数と同じタイミングで初期化される。static 変数が定義された関数が呼び出されても初期化されない。
- グローバルスコープに定義される全ての変数は let で定義されても static と同等の扱いになる。

```
func: fn1() {
  let: x1;
  static: s1;  # static変数は関数スコープ内で定義できる #
  fn4();  # ok: 関数のホイスティング #
  func: fn2() {
    let: x2;
    # x1 = 1;  Bad: 親の関数スコープにアクセス不可 #
    x2 = 1;  # ok #
    s2 = 1;  # ok: 同一スコープの static 変数にアクセス可能 #
    func: fn2a() {
    }
  }
  func: fn4() {
    fn2();  # ok: 同一スコープの関数を呼び出し #
    # fn2a();  Bad: 子スコープの関数にアクセス不可 #
  }
  fn4();  # ok #
  x1 = 1;  # ok #
  # x2 = 1;  Bad: 子スコープの変数にアクセス不可 #
}
```

- static 変数は子の関数スコープから親の関数スコープにアクセス出来る。
  親の関数スコープで定義された関数にアクセス出来るのは、全ての関数は static な定数として定義されるからである。

## 型システム

nospace は内部的に **int** と **void** の2つの型を持つ。型注釈の構文はなく、すべて自動推論される。

### int 型

- 整数値を表す型。変数、配列要素、リテラル、算術演算の結果は int 型である。
- 関数の引数と変数は int 型のみ取ることができる。

### void 型

以下の式は void 型となる：

| 式 | 条件 |
|---|---|
| if（else なし） | 常に void |
| if（else 付き） | いずれかのブロックが void の場合 |
| ブロック式 `{}` | 空の場合、または最後の式が void の場合 |
| 関数呼び出し | 呼び出し先が void 関数の場合 |
| `__trace(key)` | 常に void |

### void 型の制約

void 型の式は**値として使用できない**。以下の場所で void 式を使うとコンパイルエラーとなる：

- 変数への代入（`let: x(void_expr);` や `x = void_expr;`）
- 算術演算・比較演算のオペランド
- 関数呼び出しの引数
- 条件式（if, while の条件部）
- return の値（`return: void_expr;`）

void 式は文としてのみ使用できる（式文として評価して値を捨てる）。

TODO: より型システムが拡張されたとき、void 型の変数を定義できるようになり、代入が可能となる。この変数は実体を持たず、参照の値は常に 0 となる。void 型の変数は、型エラーを回避するためのダミー変数として使用されることが想定される。

### 関数の戻り値型

関数の戻り値型は本体の `return` 文から自動推論される：

- `return: 式;` を含む関数は **int** を返す。
- `return` 文がない関数は **void** を返す。`return:;` で void 関数から明示的に抜けることができる。
- 一部のパスでは `return: 式;` で抜け、他のパスでは暗黙の終端に到達する関数はコンパイルエラーとなる（mixed return）。

## 組み込み識別子・関数

### デバッグ・テスト用

```
__clog(5);      # 値をコンソールに出力 #
__assert(x);    # x が 0 ならパニック #
__assert_not(x); # x が 0 でなければパニック #
__trace(key);   # テスト用トレース記録 #
```

whitespace コンパイル時には無効化される。

| 識別子 | 説明 |
|--------|------|
| `__clog(x)` | 値 x をコンソールに出力し、x を返す |
| `__assert(x)` | x が 0 の場合パニック、それ以外は x を返す |
| `__assert_not(x)` | x が 0 以外の場合パニック、0 なら x を返す |
| `__trace(key)` | テスト用。key に対応するカウンタをインクリメント。戻り値は void |

### 標準入出力

```
__puti(42);     # 整数を出力 #
__putc(65);     # 文字（ASCII）を出力 #
let: n; n = __geti();  # 整数を入力 #
let: c; c = __getc();  # 1文字を入力 #
```

| 識別子 | 説明 |
|--------|------|
| `__puti(x)` | 整数 x を10進数で標準出力に出力し、x を返す |
| `__putc(x)` | x をASCII文字として標準出力に出力し、x を返す |
| `__geti()` | 標準入力から整数を読み込み、その値を返す |
| `__getc()` | 標準入力から1文字を読み込み、ASCII値を返す |

- `__geti` は空白・改行をスキップして数値を読み取る
- `__getc` は次の1バイトをそのまま読み取る（空白・改行もそのまま）
- 入力がない場合の動作は実装依存（0を返すか、エラーとするか）

過去のバージョンでは以下の組み込み関数が存在していたが、廃止予定。
これは whitespace 環境での実行効率化のために用意された関数である。

| 識別子 | 説明 |
|--------|------|
| `__getiv(p)` | 標準入力から整数を読み込み、参照 p へ格納 |
| `__getcv(p)` | 標準入力から1文字を読み込み、ASCII値を参照 p へ格納 |

### メモリ管理組み込み関数（`--std-ext alloc`）

`--std-ext alloc` オプションを有効にすると、動的メモリ管理用の組み込み関数が利用可能になる。
`--std-ext alloc` が指定されていない場合、コンパイルエラーとなる。

```
let: ptr;
ptr = __alloc(10);   # 10ワード分のメモリを確保 #
__free(ptr);         # メモリを解放 #
```

| 識別子 | 説明 |
|--------|------|
| `__alloc(n)` | n ワード分のヒープメモリを確保し、先頭アドレスを返す |
| `__free(ptr)` | `__alloc` で確保したメモリを解放し、0 を返す |
